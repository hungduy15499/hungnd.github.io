# hungngduy.github.io

Personal academic website, built with Jekyll + Tailwind CSS and deployed by GitHub Actions.

## How to update

| What | Where |
|---|---|
| Name, position, bio, links (CV, Scholar, ResearchGate, GitHub, email) | `_config.yml` |
| Profile photo | `images/portrait.jpg` |
| Publications | paste BibTeX into `_bibliography/papers.bib` |
| Blog posts | `_posts/YYYY-MM-DD-title.md` |

Publications are rendered by [jekyll-scholar](https://github.com/inukshuk/jekyll-scholar) in IEEE style.
Your name is bolded based on `scholar_me` in `_config.yml`.

**GitHub Pages setting:** Settings → Pages → Source = **GitHub Actions**.
